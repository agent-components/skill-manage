# 技能管理

## 界面说明

页面外观参考了 [SkillHub 插件页](https://skillhub.cn/plugins)。

## 它解决什么问题

技能常常留在某一个助手里。换一个助手，换一个地方，这一份就带不走。

技能管理把这一份留在你自己这边。同一份技能，任何地方、任何助手都可以用。这是给你自己部署的，不是公开的技能社区。

网站是给你看的：看看自己有什么，把技能归进项目，把访问交出去。上传和更新由助手来做。你只会看到自己的项目、技能和令牌。

## 能做什么

技能先放在你自己的库里，再按工作归进项目。分类就发生在你往令牌上放什么：你不会把库里每一份技能都交给一个助手。一个助手能看见哪些技能，记在它拿到的那张令牌上。

令牌绑在一个项目上。一张令牌就是一条自己的 MCP 连接；这条 MCP 只看见这张令牌所绑项目里的技能。换一张令牌，就是另一条 MCP，看见的是另一组技能。助手用技能的时候，不会把别的项目、别的令牌上的技能混进来。你可以限定这张令牌能做的事，也可以随时收回。

## 局限

这不适合需要跑脚本的技能。它适合的是以文档为主的技能：助手读进去、照着做的说明。

工作如果需要一段脚本或一个程序，不要把这段脚本放进技能包。你自己做命令行，或者另起一个 MCP。技能只用文字说明什么时候、怎样去调用那个 MCP 的工具，或那条命令行。可执行的东西留在技能外面。
